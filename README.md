# Certification Tracker (v3)

Public site code. All data lives in the private `tracker-data` repo in this organization and is
read through the GitHub API with an access key (viewers: read-only key; editor: read-and-write key).

- `index.html` — view-only page (asks for an access key on first visit)
- `admin/project-management.html` — editor
- `assets/` — shared code and styles (`atd.js`: FAA ATD approvals page)
- `changelog.html` — change log
